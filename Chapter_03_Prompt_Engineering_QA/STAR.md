
# STAR


## S - Situation:

I am a QA engineer preparing to test the login page at https://app.vwo.com/. For this exercise, assume the approved requirements are:

- Registered users can log in with valid credentials.
- Invalid credentials must not grant access.
- Email and password are mandatory.
- Successful login opens the authenticated dashboard.
- Invalid login gives a Error Message "Your email, password, IP address or location did not match"


## T - Task:

Create a functional Test plan for login module use the template here Chapter_03_Prompt_Engineering_QA\template.md


## A - Action:

1. Define the objectives, scope, and testing approach.
2. Cover valid login, invalid credentials, empty fields, and access to the dashboard after login.
3. Include positive, negative, and boundary scenarios where the supplied requirements support them.
4. Define test environment needs, test data, entry criteria, exit criteria, deliverables, and risks.
5. Mark unspecified behavior as “Requires clarification.” Do not invent password rules, exact error messages, or session timeouts.



## R - Result:

Return a test plan containing:

- Test Plan ID and Title
- Objective
- In Scope and Out of Scope
- Test Approach
- Test Scenarios
- Environment and Test Data
- Entry and Exit Criteria
- Deliverables
- Risks and Open Questions


Use clear language and tables where useful. Label any proposed criteria as recommendations.
